# Recognition Task 5: Lesions Detection with YOLOv7

---
### Description of Algorithm
This report uses the You Only Look Once (YOLO) v7 model. YOLO models are single stage object detectors which are, in turn, deep learning models that are able to find and identify objects in a single pass through the Convolutional Neural Network. Unlike two-stage object detectors, YOLO models immediately predict bounding boxes and classes from the image in a single pass. YOLO models are widely used for modeling object detection as they are faster, trainable on a single GPU, and can be used for real-time detection.
